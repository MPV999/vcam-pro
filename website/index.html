Real capture

CameraX photo and video capture with zoom, torch, exposure compensation, timer and grid — whatever the device actually supports.

Private library

Room-backed library in app-scoped storage. Import with the Storage Access Framework, export through MediaStore. Nothing is scanned behind your back.

Streaming decode

MediaExtractor → MediaCodec → GL. A 4 GB video never lands in RAM; only a bounded set of frames exists at any moment.

Virtual camera SDK

CameraSource, FrameConsumer, PlaybackController and CameraSession. YUV_420_888, NV21 or RGBA output with a hard memory ceiling.

Honest limits

Android gives no public API for replacing the system camera for other apps. Frames only reach apps that integrate the SDK. No root, no Magisk, no Xposed.

Zero infrastructure

No backend, no Firebase, no paid API. The APK works offline from the moment it is installed.

Requirements

  • Android 10 (API 29) or newer, arm64 device.
  • A camera for Camera Studio; the virtual camera also works from imported files.
  • Camera and microphone permissions for capture — both optional for library and SDK use.
  • No network permission is required by the app itself.

Install

  1. Download the APK from the latest release.
  2. Allow installing unknown apps for your browser when Android asks.
  3. Verify the SHA-256 printed on the release against the downloaded file.
  4. Open VCAM Pro, grant camera access, record a clip in Camera Studio.
  5. Open the library, pick the clip, then open Virtual Camera Studio to stream it.
  6. Install the integration sample APK to see those frames inside another app.
